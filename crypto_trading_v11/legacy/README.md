# ملفات تاريخية — لا تُشغَّل

هذه الملفات محفوظة للتوثيق فقط. **ممنوع استخدامها في أي مسار إنتاجي.**

## محرك الباكتست الرسمي الوحيد

```
src/backtest/engine.py  →  BacktestEngine
```

هو المصدر الوحيد للحقيقة. أي محرك آخر هنا:

- لا يطبّق التكاليف بشكل صحيح
- قد يحوي انحياز نظر للأمام
- أرقامه **باطلة** لا مبالغ فيها

## لماذا لم تُحذف

للرجوع عند تتبّع كيف تطوّر المشروع، وللمقارنة عند الشك في نتيجة.

`legacy/` مستبعد من `compileall` ومن اكتشاف الاختبارات.
