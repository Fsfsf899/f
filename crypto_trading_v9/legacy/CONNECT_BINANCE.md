# ربط بينانس — الدليل الكامل

## الأوضاع الثلاثة

| الوضع | الأوامر | المال | الأمر |
|---|---|---|---|
| `paper` | لا تُرسل | لا شيء | `python3 live_bot.py paper` |
| `testnet` | حقيقية | وهمي | `python3 live_bot.py testnet` |
| `live` | حقيقية | 🔴 حقيقي | `python3 live_bot.py live` |

الوضع `live` يشغّل بوابة التحقق أولاً، وإذا فشلت يتوقف.

---

## الخطوة 1 — مفاتيح Testnet

1. ادخل https://testnet.binance.vision
2. سجّل بحساب GitHub
3. **Generate HMAC_SHA256 Key**
4. انسخ Key و Secret فوراً (الـ Secret يظهر مرة واحدة)

```bash
cp .env.example .env
# ضع المفاتيح داخل .env
python3 live_bot.py check
```

المتوقع:
```
✅ الوصول للخادم
✅ مزامنة الوقت
✅ صلاحية التداول: نعم
✅ الأرصدة: USDT: 10000.00000000
```

---

## الخطوة 2 — شغّل على Testnet

```bash
python3 live_bot.py testnet
```

أوامر حقيقية بأموال وهمية. اتركه أسبوعين على الأقل.
كل صفقة تُحفظ في `bot_state.json`.

---

## الخطوة 3 — بوابة التحقق

```bash
python3 live_bot.py validate
```

يشغّل باكتست على بيانات بينانس الحقيقية ويفحص:

| الشرط | الحد | لماذا |
|---|---|---|
| عدد الصفقات | ≥ 100 | أقل من هذا = ضجيج إحصائي |
| Profit Factor | ≥ 1.3 | 1.0 تعادل؛ الهامش للأمان |
| ثبات Walk-Forward | ≥ 0.75 | 3 نوافذ رابحة من 4 |

**الوضع الحقيقي لن يعمل قبل اجتياز الثلاثة.**

هذه الحدود ليست تعجيزية — هي الحد الأدنى الفاصل بين استراتيجية وقمار.
تقدر تعدّلها في `live_bot.py` → `ValidationGate`، لكن تخفيضها لا يجعل
الاستراتيجية أفضل، فقط يخفي أنها غير جاهزة.

---

## الخطوة 4 — مفاتيح حقيقية

في binance.com ← API Management:

- ✅ **Enable Spot Trading** فقط
- ❌ **Enable Withdrawals** — لا تفعّله إطلاقاً
- ❌ Futures / Margin — لا
- ✅ **Restrict access to trusted IPs** — ضع IP جهازك

بهذه القيود، حتى لو تسرّب مفتاحك، لا أحد يقدر يسحب أموالك.

```bash
python3 live_bot.py live
```

يبدأ بحد $25 للمركز الواحد. ارفعه فقط بعد 50 صفقة حقيقية موثّقة.

## طبقات الأمان في الكود

| الطبقة | التفصيل |
|---|---|
| بوابة التحقق | تمنع `live` قبل إثبات الربحية |
| وقف على المنصة | `STOP_LOSS_LIMIT` يعمل حتى لو انطفأ جهازك |
| حد المركز | `MAX_POSITION_USD` سقف صارم |
| حد يومي | توقف عند خسارة 3% |
| سلسلة خسائر | توقف بعد 4 خسائر متتالية |
| مركز واحد | لا تعدد مراكز |
| حالة محفوظة | `bot_state.json` يستعيد بعد انقطاع |

## الأخطاء الشائعة

| الخطأ | السبب | الحل |
|---|---|---|
| `-2015` | مفتاح خاطئ أو IP غير مسموح | راجع القيود |
| `-1021` | ساعة جهازك متأخرة | صحّح وقت النظام |
| `-1013 LOT_SIZE` | كمية غير مقرّبة | الكود يعالجها تلقائياً |
| `NOTIONAL` | قيمة أقل من $10 | ارفع `MAX_POSITION_USD` |
| `403` | حجب جغرافي | VPN |

## الحقيقة التي يجب أن تعرفها

الكود صحيح وجاهز — التوقيع محقّق ضد المثال الرسمي في وثائق بينانس.

**لكن الاستراتيجية نفسها لم تُثبت ربحيتها.** كل اختبار أعطى Profit Factor
أقل من 1.0 بعد الرسوم. بوابة التحقق موجودة لهذا السبب بالذات.

شغّل `validate` على بيانات حقيقية. إن اجتازت، امضِ. إن لم تجتز، فالمشكلة
في الاستراتيجية لا في الربط — ولا يوجد إعداد في هذا الملف يصلحها.
