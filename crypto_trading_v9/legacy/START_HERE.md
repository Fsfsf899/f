# ابدأ من هنا

## التشغيل — 3 خطوات

```bash
# 1. تأكد من الاتصال ببينانس
python3 real_data.py check

# 2. شغّل الموقع
python3 dashboard.py

# 3. افتح المتصفح (يفتح تلقائياً)
http://localhost:8000
```

اضغط **تشغيل التحليل** في الموقع. أول مرة يأخذ 30-90 ثانية لتحميل البيانات،
وبعدها يستخدم الكاش ويصير فورياً.

**المتطلبات:** Python 3.8+ و numpy فقط.
```bash
pip install numpy
```
لا Flask ولا ccxt ولا أي شي ثاني.

---

## الأرقام حقيقية — إليك الضمان

- البيانات من `api.binance.com` مباشرة (شموع حقيقية، تواريخ حقيقية)
- الرسوم 0.10% ذهاباً وإياباً + انزلاق 0.05% مطروحة من كل صفقة
- الانزلاق عند وقف الخسارة مضروب ×2.5 (لأن السوق يتحرك ضدك بسرعة هناك)
- **إذا فشل جلب البيانات، الموقع يعرض خطأً أحمر ولا يعرض أي رقم**

لن ترى رقماً مولَّداً في هذه النسخة. أزلت كل مسارات البيانات التجريبية من الواجهة.

## إذا كان بينانس محجوباً عندك

خطأ 403 يعني حجب جغرافي (السعودية وبعض الدول). الحلول:

**أ. VPN** — أبسط حل.

**ب. CSV يدوي** — نزّل بيانات من CryptoDataDownload أو TradingView، ثم:
```python
import real_data
data = real_data.load_csv('btc_4h.csv')
```
الأعمدة: `time, open, high, low, close, volume`

## كيف تقرأ النتيجة

| المؤشر | المعنى |
|---|---|
| **Profit Factor** | أهم رقم. فوق 1.3 = واعد. تحت 1.0 = خاسرة |
| **عدد الصفقات** | تحت 30 = لا استنتاج ممكن. تحتاج 100+ |
| **Walk-Forward** | 3 نوافذ رابحة من 4 = مستقر. أقل = ضجيج |
| نسبة الفوز | مضلِّلة وحدها. 40% مع R:R 3:1 أفضل من 60% مع 1:1 |

**القاعدة:** لا تربطه بحساب حقيقي قبل: PF > 1.3، و100+ صفقة، و3/4 نوافذ رابحة.

## طريقة البحث عن إعداد رابح

جرّب هذا الترتيب في الموقع، وسجّل النتائج:

1. **BTCUSDT / يومي / 1095 يوم** — أقل تكاليف، ابدأ هنا
2. **BTCUSDT / 4 ساعات / 730 يوم**
3. جرّب حد النقاط 3 و4 و5
4. جرّب ETHUSDT و SOLUSDT

كل تشغيلة تأخذ ثوانٍ. غيّر متغيراً واحداً في كل مرة.

**تحذير مهم:** إذا جربت 40 تركيبة ووجدت واحدة رابحة، فغالباً وجدت صدفة لا حافة.
هذا اسمه p-hacking. الاختبار الحقيقي هو ثبات Walk-Forward، وليس أفضل رقم رأيته.

## أين تعدّل الاستراتيجية

كل منطق الإشارة في دالة واحدة:
`final_engine.py` → `FinalSignalEngine.evaluate()`

بُنيت على ثلاث مراحل:
1. **بوابات إلزامية** — أي فشل = رفض فوري (حالة السوق، الإطار الأكبر، ADX، التقلب)
2. **نقاط تأكيد** — RSI، الحجم، أنماط الشموع
3. **جودة الموقع** — قرب المقاومة، منطقة القيمة

بدّل ما بداخلها بأي فكرة، والباقي (التكاليف، الخروج، المخاطر، التحقق، الموقع)
يشتغل كما هو. هذه هي القيمة الحقيقية للمشروع.
