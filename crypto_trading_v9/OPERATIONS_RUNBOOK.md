# دليل التشغيل المستمر بلا إشراف

هذا الدليل يخص شيئاً واحداً فقط: **كيف تُشغِّل `paper` لمدة 14 يوماً
فأكثر بلا أن تراقب طرفية مفتوحة طوال الوقت.**

⚠️ **لا شيء هنا يغيّر حالة بوابة Live.** `live-status` يبقى `⛔ ممنوع`
بغض النظر عن مدة تشغيل هذا المراقب. الغرض الوحيد: جعل جمع بيانات
Paper/Testnet الحقيقية ممكناً عملياً، لا أكثر.

---

## البدء

```bash
python3 watchdog.py paper
```

هذا يستبدل `python3 live_trader.py paper` المباشر. إن انهار المحرك
لأي سبب (استثناء غير متوقَّع، انقطاع شبكة لم تلتقطه طبقة إعادة
المحاولة الداخلية، إلخ)، يُعيد المراقب تشغيله تلقائياً بتصاعد زمني
(5ث → 10 → 20 → ... → سقف 5 دقائق)، حتى 10 انهيارات خلال ساعة. بعدها
يتوقف المراقب نفسه ويُنبِّهك بدل إعادة المحاولة إلى ما لا نهاية بصمت
— انهيار متكرر يعني خللاً حقيقياً يستحق فحصك اليدوي، لا مزيداً من
إعادة التشغيل الأعمى.

للتشغيل في الخلفية على جهازك:

```bash
nohup python3 watchdog.py paper > watchdog.log 2>&1 &
```

أو داخل `tmux`/`screen` حتى تستطيع إعادة الاتصال لاحقاً:

```bash
tmux new -s trading
python3 watchdog.py paper
# Ctrl+B ثم D للخروج بلا إيقاف
```

## التنبيهات (اختياري)

بلا أي ضبط، لا يُرسَل شيء — النظام يعمل بصمت كما كان دائماً. لتفعيل
تنبيهات فورية عند الأحداث الحرجة، أضف في `.env`:

```bash
NOTIFY_TELEGRAM_BOT_TOKEN=...
NOTIFY_TELEGRAM_CHAT_ID=...
# أو
NOTIFY_WEBHOOK_URL=https://...
```

### متى تصلك رسالة

| الحدث | الخطورة | ملاحظة |
|---|---|---|
| بدء/إيقاف التشغيل | INFO | مرة واحدة لكل جلسة |
| تفعيل مفتاح الإيقاف | CRITICAL | التداول توقف — أي سبب |
| تحرير مفتاح الإيقاف بالقوة (`--force`) | CRITICAL | تجاوز يدوي واعٍ |
| 3 أعطال متتالية داخل الحلقة | HIGH | لم تصل بعد لحد الانهيار الكامل |
| المراقب يُعيد التشغيل | HIGH | مرة لكل انهيار فعلي للعملية |
| المراقب يستسلم (>10 انهيارات/ساعة) | CRITICAL | توقف كل شيء — يلزم فحص يدوي |

كل رسالة **مُبرَّدة لمفتاح الحدث نفسه** (300 ثانية افتراضياً) — حالة
متكررة (مثل عطل API متتالٍ) لا تُغرق قناتك برسالة كل دقيقة.

**لا يُرسَل أي سر أو مفتاح API في أي رسالة** — النص يمر عبر نفس دالة
الحجب المستخدمة في سجلات النظام.

## كيف تتحقق من الحالة بلا فتح الطرفية

```bash
python3 live_trader.py health --env paper     # هل النظام سليم الآن؟
python3 live_trader.py report --env paper     # هل التوصيات تربح حتى الآن؟
python3 live_trader.py intents --env paper    # أي نوايا أوامر عالقة؟
```

هذه أوامر **قراءة فقط** — تعمل بينما `watchdog.py` يعمل في الخلفية
بلا تعارض.

## عند وصولك تنبيه "Giving Up"

المراقب توقف عمداً. لا تُعِد تشغيله فوراً بلا فحص:

1. `python3 live_trader.py health --env paper` — ما السبب الجذري؟
2. راجع آخر أسطر `watchdog.log`
3. أصلح السبب (غالباً: بيانات بينانس محجوبة، أو انقطاع شبكة طويل)
4. عندها فقط: `python3 watchdog.py paper` من جديد
